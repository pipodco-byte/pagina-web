Glosario Técnico: Capítulo 1 - Introducción a la IA

A continuación se detallan los términos clave extraídos del Syllabus ISTQB CT-AI v1.0, organizados por subsección técnica.

1. Fundamentos y Clasificación (Definiciones)

Artificial Intelligence (AI) / Inteligencia Artificial (IA): Capacidad de un sistema para interpretar datos, aprender y adaptarse para lograr objetivos específicos.

AI Effect / Efecto IA: Fenómeno perceptivo donde una tecnología deja de considerarse "inteligencia" una vez que se vuelve común o se entiende su funcionamiento.

Narrow AI (Weak AI) / IA Estrecha (IA Débil): IA diseñada para una tarea única y específica (ej. reconocimiento de voz). Es la única IA existente hoy.

General AI (Strong AI) / IA General (IA Fuerte): IA teórica con capacidades cognitivas iguales a las humanas en múltiples dominios.

Super AI / Super IA: IA teórica que supera significativamente la inteligencia humana en todos los campos.

Conventional Systems / Sistemas Convencionales: Software basado en reglas explícitas (if-then-else) y lógica determinista programada por humanos.

AI-Based Systems / Sistemas Basados en IA: Software cuya lógica se deriva de patrones en los datos mediante algoritmos de aprendizaje.

Deterministic / Determinista: Sistema que ante una misma entrada siempre produce la misma salida.

Probabilistic / Probabilístico: Sistema que produce resultados basados en probabilidades; la salida puede variar o incluir un nivel de confianza.

2. Tecnologías de Aprendizaje (Machine Learning)

Machine Learning (ML) / Aprendizaje Automático: Rama de la IA que permite a las máquinas aprender de los datos sin programación explícita.

Deep Learning (DL) / Aprendizaje Profundo: Subcampo del ML basado en redes neuronales artificiales con múltiples capas (Deep Neural Networks).

Supervised Learning / Aprendizaje Supervisado: Entrenamiento con datos etiquetados (pares entrada-salida conocida).

Unsupervised Learning / Aprendizaje No Supervisado: El modelo busca estructuras o agrupamientos (clustering) en datos no etiquetados.

Reinforcement Learning (RL) / Aprendizaje por Refuerzo: Agente que aprende mediante ensayo y error recibiendo recompensas o penalizaciones.

Agent / Agente: La entidad de IA que toma decisiones en un entorno de Reinforcement Learning.

Environment / Entorno: El mundo o simulación con el que interactúa el Agente en RL.

Reward / Recompensa: Señal numérica que indica el éxito de una acción en RL.

Reward Hacking / Hackeo de Recompensa: Defecto donde la IA encuentra un atajo para obtener la recompensa sin cumplir el objetivo real.

Natural Language Processing (NLP) / Procesamiento de Lenguaje Natural: Tecnología para la comprensión y generación de lenguaje humano.

Computer Vision / Visión Artificial: Tecnología para que las máquinas procesen e interpreten imágenes y videos.

3. Desarrollo, Hardware y Servicios

AI Development Frameworks / Marcos de Desarrollo de IA: Bibliotecas de software (TensorFlow, PyTorch, Scikit-learn) para construir modelos.

CPU (Central Processing Unit): Procesador de propósito general.

GPU (Graphics Processing Unit): Procesador paralelo ideal para el entrenamiento masivo de redes neuronales.

TPU (Tensor Processing Unit): Hardware especializado (ASIC) diseñado específicamente para operaciones de tensores en IA.

AI as a Service (AIaaS) / IA como Servicio: Capacidades de IA ofrecidas por proveedores de nube (Azure, AWS, Google Cloud) mediante APIs.

Pre-trained Models / Modelos Pre-entrenados: Modelos ya entrenados con grandes datasets que se pueden reutilizar.

Fine-tuning / Ajuste Fino: Re-entrenamiento ligero de un modelo pre-entrenado con datos específicos de un nuevo dominio.

Catastrophic Forgetting / Olvido Catastrófico: Pérdida de conocimientos previos al intentar aprender información nueva durante el fine-tuning.

4. Calidad y Regulación

Bias / Sesgo: Prejuicio o error sistemático en los datos de entrenamiento que produce resultados injustos o incorrectos.

Autonomous Systems / Sistemas Autónomos: Sistemas que pueden operar y tomar decisiones sin intervención humana constante.

EU AI Act / Ley de IA de la UE: Primera regulación integral que clasifica la IA por niveles de riesgo.

High-Risk AI / IA de Alto Riesgo: Categoría de sistemas que requieren auditorías estrictas y pruebas de calidad obligatorias (ej. salud, transporte).

ISO/IEC 42001: Estándar internacional para la gestión de sistemas de IA.

ISO/IEC TR 24029-1: Informe técnico sobre la evaluación de la robustez de redes neuronales.

Test Oracle / Oráculo de Prueba: Mecanismo para determinar si el resultado de una prueba es correcto o incorrecto (un gran reto en IA).
