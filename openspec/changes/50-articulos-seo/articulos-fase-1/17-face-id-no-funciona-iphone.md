# Face ID No Funciona: Reparación del Sensor TrueDepth en tu iPhone

El Face ID dejó de funcionar. Aparece el mensaje "Mover un poco más alto/bajo" o directamente no responde. Perdiste la forma más segura y rápida de desbloquear tu iPhone. En Pipod reparamos el sistema TrueDepth.

---

## ¿Por Qué Falla el Face ID?

### 1. Daño en la Pantalla (Reemplazo Previo)

**Sucede cuando:**
- Cambiaste la pantalla en otro taller
- El técnico no transplantó el sensor original
- Se dañaron cables flex del TrueDepth

**Solución:** Transplante del sensor original a nueva pantalla.

### 2. Fallo del Proyector de Puntos

**Síntomas:**
- "Mover iPhone un poco más alto"
- "Mover iPhone un poco más bajo"
- Luz infrarroja no proyecta patrones

**Causas:**
- Golpe en área del notch
- Caída del iPhone
- Humedad en componentes

**Solución:** Reemplazo del módulo TrueDepth completo.

### 3. Cámara Infrarroja Dañada

La cámara IR lee el patrón de puntos proyectado. Si falla, no hay reconocimiento.

**Solución:** Reemplazo de cámara IR.

### 4. Cámara RGB Frontal

La cámara frontal captura la imagen 2D para comparación. Si falla, el sistema no funciona.
