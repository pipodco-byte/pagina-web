## Métodos de Recuperación de Datos iPhone en Bogotá

### Método 1: Reparación Temporal
- Reparamos el iPhone lo suficiente para encender
- Extraemos datos mientras funciona
- No garantizamos reparación permanente

### Método 2: Extracción Directa de Memoria
- Accedemos directamente al chip de almacenamiento
- Requiere microsoldadura avanzada
- Para casos de placa muy dañada
- Complejidad alta

### Método 3: Backup Desde iTunes/iCloud
- Si hay backup previo
- Restauración a otro equipo
- Más sencillo y económico
